# README GIF provenance

The GIFs in this directory were assembled on 2026-08-20 from screenshots supplied for the UndertaleModTool WinUI Preview README. They show the real WinUI interface browsing a Deltarune `data.win` file, including sprite, texture, code, shader, and font resource views.

The captures are slideshow-style tours rather than continuous recordings. They were scaled to 960 pixels wide and exported with FFmpeg at 8 FPS using a deterministic 128-color palette, Bayer dithering, differential rectangles, and infinite looping. Exact dimensions, frame counts, sizes, and SHA-256 hashes are recorded in `manifest.json`.
